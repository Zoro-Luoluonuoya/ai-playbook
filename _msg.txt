docs: 新增使用手册（基于 Codex 桌面版实测）

为什么：前面三轮陌生人测试 + 这次真 Codex 实测，攒下的操作细节都散在对话里，
换环境时没法复用。需要一份"照着做就行"的手册，含实测踩到的坑。

做什么：
1. docs/使用手册.md：三段式流程（新电脑准备 / 每个新项目装一次 / 日常干活）
   + 生效验证方法（占位符测试）+ 六个实测坑 + 排错表 + 能保证/不能保证清单。
2. README 安装段加指引。

关键内容（实测得来，不是推演）：
- 桌面版终端是 PowerShell 而非 bash，列目录加 -la 会报参数错误；
- where.exe bash 第一条是 System32 的 WSL，必须显式指定 Git 自带的 bash；
- 装完第一次跑 verify 一定红 2 项，是设计如此；
- 中文路径实测没问题；
- 确认它真读了规则用占位符测试（10 秒，比跑脚本有效）。

边界：只加文档，不改代码与规则。
验证：Markdown 结构与既有文档一致；命令块均为实测过的写法。
