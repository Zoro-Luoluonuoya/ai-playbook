# 每日三问（收工前 2 分钟，答完就关）

**1. 今天交付的东西，五层验证里哪层没跑？**
→ 动作：在交付说明第一行写 `未跑：L<n> <层名>（原因）`；五层全跑就写 `五层全跑`。（V8 / M-008）

**2. 今天有没有一个「我以为验证过」的结论？**
→ 动作：挑一条断言做反向验证——把被测代码改坏一处，看断言是否变红；不变红就当场修断言。（V1 / M-007 / M-012）

**3. 今天有没有一次卡住、返工、或让用户替我操作机器？**
→ 动作：写一条 MISTAKE-LOG（流程摩擦也收）；真的没有就写「今日无」，不许空着。（骨架 B4 / B11）

超时即失败：2 分钟没答完，说明第 3 问在凑数，直接写「今日无」。
